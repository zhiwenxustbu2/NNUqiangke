# 南师大选课监控助手

这是一个无需额外运行环境的 Chrome Manifest V3 扩展。它只在已经登录的南京师范大学选课页面中工作，不保存密码、Cookie、学号或登录令牌。

## 首次安装

1. 将 `抢课扩展.zip` 解压到一个固定文件夹，后续不要随意删除或移动。
2. 在 Chrome 地址栏输入 `chrome://extensions`。
3. 打开右上角的“开发者模式”。
4. 点击“加载已解压的扩展”，选择包含 `manifest.json` 的 `course-grabber-extension` 文件夹。
5. 建议点击 Chrome 工具栏的拼图图标，将“南师大选课监控助手”固定到工具栏。

Chrome 不允许普通扩展静默安装，因此每台电脑第一次都需要完成以上步骤。以后只需点击扩展图标。

## 使用前准备

1. 在同一个 Chrome 中登录学校选课网站，并保持“选课”页面打开。
2. 点击扩展图标打开控制面板。
3. 输入课程完整名称或课程号；多个目标每行一个。
4. 点击“查找可选班级”，为每门课选择明确的老师和课序号。
5. 先点击“演练检查”，确认能读取正确容量。演练不会提交选课。

## 手动运行

点击“立即开始监控”，核对确认框里的课程、栏目、老师和课序号。确认后程序立即开始，全局每秒查询一个目标，直到：

- 所有目标选课成功；
- 你点击“停止监控”；
- 登录失效或出现无法安全继续的页面变化。

手动运行不受自动结束时间限制。

## 自动运行

先在控制面板中选择每天的“自动开始”和“自动结束”时间，点击“保存自动时间”，再打开“每日自动运行”开关并确认目标课程。时间采用北京时间，精确到秒；结束时间早于开始时间时表示跨午夜运行。扩展会：

- 在开始时间前 5 秒聚焦已登录的选课标签页并防止电脑继续休眠；
- 到达用户设置的开始时间后监控；
- 到达用户设置的结束时间后停止自动任务；
- 未完成课程保留到次日，成功目标不会重复提交。

电脑关机、已经休眠或 Chrome 未运行时，扩展无法自行唤醒电脑。请在自动开始前保持电脑开机、Chrome 正在运行且选课页面仍处于登录状态。

扩展的“每秒查询”是调用学校选课页自身的实时容量接口，每次都会重新向服务器读取容量，但不会像按 F5 那样整页刷新或造成页面闪烁。

## 成功与失败提醒

- 一门课程确认成功后会永久跳过，不会再次提交。
- 所有目标成功后，监控、每日自动开关和相关定时任务会自动关闭。
- 登录失效、接口缺失或学校明确拒绝等需要处理的失败，会在控制面板顶部显示红色横幅，并在扩展图标上显示红色感叹号。
- 点击“我知道了”只清除横幅和角标，不会删除失败状态或日志；修正原因后可重新解析课程或重置运行结果。
- 系统通知无法显示时只会写入提醒日志，不会影响成功状态或触发重复选课。

## 在另一台电脑使用

1. 在原电脑点击“导出配置”。配置文件不包含登录信息。
2. 在另一台电脑安装扩展并登录选课网站。
3. 点击“导入配置”。
4. 因教学班 ID 可能随学期或电脑页面状态变化，导入后的目标会被标记为需要重新解析；逐项点击“修改”，重新选择同一老师和课序号。
5. 完成后先运行演练检查，再启动正式监控。

导出的配置会包含自动开始和结束时间；导入后每日自动开关始终保持关闭，需要重新确认后启用。

## 安全边界

- 扩展只获得 `https://xsxk.nnu.edu.cn/*` 的站点权限。
- 只有控制面板确认过的具体教学班能够触发提交。
- 同一时间只有一个容量查询或提交流程，避免重复提交。
- 如果网站要求选择教材订购方式，扩展会阻止该目标，不会擅自产生教材订单。
- 实验课程必须明确选择实验班。
- 扩展不会处理或绕过验证码、登录限制、容量限制、时间冲突等网站规则。
- 请自行确认自动化选课符合学校当前规定，使用者承担配置和使用责任。

## 常见问题

### 提示“未找到已登录的选课页面”

在同一个 Chrome 窗口重新登录选课网站，进入标题为“选课”的页面后再试。

### 自动任务没有启动

检查每日自动开关、保存的开始和结束时间、系统时间、Chrome 是否运行、电脑是否已经休眠，以及选课登录是否过期。

### 课程显示“已停止”

查看运行日志。修正课程冲突、实验班缺失、登录失效或页面变化后，点击“重置运行结果”再启动。

### 如何确认不会误选

正式启动前，确认框会逐项列出课程、栏目、老师和课序号。建议先使用“演练检查”。
